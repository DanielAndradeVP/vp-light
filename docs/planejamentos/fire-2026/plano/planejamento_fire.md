# Planejamento de Iluminação — Fire 2026

Data da criacao: 05/07/2026

## 1. Objetivo do planejamento

Este planejamento existe para organizar a iluminação do Fire 2026: deixar claro o que já temos, o que precisa ser resolvido e como vamos operar as cenas durante o evento, sem depender de improviso na hora.

Parte central desse plano é o uso do vplight, um programa desenvolvido pela nossa própria equipe. Ele foi criado para trazer para dentro do nosso sistema as ferramentas mais recentes de tecnologia de iluminação, mas de uma forma que podemos moldar do nosso jeito — criando nossas próprias ferramentas e lógicas de operação, em vez de ficar limitados ao que um software pronto de mercado permite.

## 3. Plano de melhoria

### Equipamentos
resolver os equipamentos para que possamos ter:
10 par leds funcionando 100% (arrumar 4und com defeito nos leds), 6 bruts 100% funcionando (as 4 lampadas cada um),6 ribaltas na estrutura do gride (2 brancas + 4 que fazem cor)
maquina de fumaca: ja temos fluido suficiente para passar o fire.

### Software de operação
Criar uma base com **50 scripts de cenas para a iluminação**, suprindo diferentes momentos do evento, como abertura, louvor, pregação, transições e encerramento. O objetivo é ter uma variedade de cenas prontas para uso, com diferentes combinações de cores, movimentos e efeitos, permitindo que a operação da iluminação acompanhe cada momento do evento de forma organizada, consistente e sem depender de improvisos.


### Organização das cenas/efeitos
organizando esses scripts em grupos de execucao (lento,medio,rapido) para saber o melhor momento para usalos quando estiver operando.
